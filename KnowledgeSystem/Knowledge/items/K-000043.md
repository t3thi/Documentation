# Define language eligibility for copies into shared storage

## Statement

Ordinary content copies should respect the configured Site Languages
and the target page's available languages. Which eligibility rule should
apply to storage folders, including those outside sites, or `pid=0`?

## Rationale

Shared translated records can lack a site or page-language context.
Gerrit 92777's review distinguishes the source language from the
effective language after a paste override. Validating only the source
cannot establish target eligibility.

## Consequences

Test translated sources and explicit target-language overrides. The
meeting did not select a storage-folder exemption, a rule for `pid=0`,
or a 14.3 backport policy.
