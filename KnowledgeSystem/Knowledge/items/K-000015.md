# l10n_state can disagree with stored values

## Statement

An empty or missing `l10n_state` entry does not prove that the localized stored
value equals its parent. Current state enrichment treats a missing configured
field state as `parent` without comparing values.

## Rationale

Existing data can therefore present a field as inherited while retaining a
different stored value. The open dbdoctor repair proposal demonstrates the
inconsistency but is not merged Core behavior.

## Consequences

Migration must reconcile metadata, scalar values and relations without
overwriting intentional manual differences merely because state metadata is
missing.
