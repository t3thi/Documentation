# Complete per-language layers are disfavored, not rejected

## Statement

One possible model materializes every structural position in every relevant
language and uses language-layer shadows where visible content is absent. The
initiative currently disfavors this direction relative to a shared layer, but
has not rejected or disproved it.

## Rationale

The model provides self-contained language structures and local ordering, but
may multiply generated records, synchronization work, Workspace versions,
references and visible Layout density.

## Consequences

The option remains active for comparative prototyping. Performance and volume
claims must be measured rather than treated as settled facts.
