# Recycler shares the language selector but retains single-language selection

## Statement

Gerrit 96916 merged for TYPO3 v15 on 2026-10-22. Recycler and record history
now use `LanguageSelectorBuilder::buildForSiteLanguages()`. This is a shared
single-select, not the comparison-overlay multi-select discussed on September 4.

## Rationale

Recycler represents the unrestricted selection with `null`, not a synthetic
language record. With a concrete language selected, `DeletedRecords::setData()`
includes that language and stored Language All; non-language-aware tables are
not filtered by language. Record history has no unrestricted entry.

## Consequences

This delivers bounded selector and query consistency. It neither implements
arbitrary explicit language sets in Recycler nor removes synthetic selection
from all other backend paths. K-000029 therefore remains an active direction,
not a completed migration. Static code inspection establishes this scope;
no interactive Recycler acceptance test was run in this audit.
