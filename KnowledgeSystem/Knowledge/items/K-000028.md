# Language-All backend visibility is bounded preparatory work

## Statement

The initiative proposed a bounded backend improvement that displays an
existing `sys_language_uid = -1` record in every language column at the
sorting position where it affects output. Gerrit 95475 now provides a WIP Core
implementation of that proposal. It retains the current Language-All storage
and output contract and is not merged Core behavior.

## Rationale

Showing the shared record in every affected language would reduce surprises
between backend editing and frontend output. It would also let editors become
familiar with seeing the logical position in each language before any later
migration to explicit concrete records is designed.

## Consequences

The work must complete review of sorting and Layout-module behavior without
changing the current complete-record semantics of `-1`. It remains an interim
usability and preparation step, not evidence that a hidden-structure
representation, a Language-All replacement or a long-term architecture has
been selected.
