# Language-All backend visibility is proposed preparatory work

## Statement

The initiative proposed a bounded backend improvement that displays an
existing `sys_language_uid = -1` record in every language column at the
sorting position where it affects output. The proposal retains the current
Language-All storage and output contract; no Core patch or implementation is
yet registered.

## Rationale

Showing the shared record in every affected language would reduce surprises
between backend editing and frontend output. It would also let editors become
familiar with seeing the logical position in each language before any later
migration to explicit concrete records is designed.

## Consequences

The work must characterize sorting and Layout-module behavior without changing
the current complete-record semantics of `-1`. It is an interim usability and
preparation step, not evidence that a hidden-structure representation, a
Language-All replacement or a long-term architecture has been selected.
