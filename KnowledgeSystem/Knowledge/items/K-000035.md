# Language-zero lookup correction remains separate from missing-zero validation

## Statement

Patch set 1 changes `Site::getDefaultLanguage()` from taking the first
configured language to `$this->languages[0] ?? reset($this->languages)`.
Its tests cover reordered languages and the first-language fallback when `0`
is absent. The official check found `NEW`, mergeable, CI and Code-Review `+1`,
with one unresolved comment. It targets TYPO3 v15 and names 14.3 as an intended
release; that footer alone does not establish a merged backport.

## Rationale

The meeting supports a dependable internal `0` reference and asked André to
replace the missing-zero fallback with validation failure. This is different
from making the real Default Language ID arbitrary or giving `0` permanent
semantic human-language identity.

## Consequences

The requested error is not present in the inspected revision. Neither the
patch nor the meeting establishes merged Core behavior, an adopted structure
model or formal abandonment of the older configurable-default Gerrit change.
The author's decision not to pursue that older route is not a Gerrit status.
