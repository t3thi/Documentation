# Language-zero lookup correction remains separate from missing-zero validation

## Statement

Gerrit 97053 (TYPO3 v15) and 97225 (14.3) merged on 2026-10-30.
`Site::getDefaultLanguage()` now returns
`$this->languages[0] ?? reset($this->languages)`. Tests cover reordered
languages, the missing-zero fallback and frontend site-root redirection.
For reordered sites, default links and root redirection now follow `0`;
sites without `0` deliberately retain their previous first-language fallback.

## Rationale

The meeting supports a dependable internal `0` reference and asked André to
replace the missing-zero fallback with validation failure. This is different
from making the real Default Language ID arbitrary or giving `0` permanent
semantic human-language identity.

## Consequences

The lookup correction is implemented, but the requested missing-zero error
remains unimplemented. This is not adoption of a hidden structural layer.
The older configurable-default change 84338 was separately abandoned on
2026-10-23; that official lifecycle observation is distinct from the author's
earlier meeting statement that he no longer intended to pursue it.
