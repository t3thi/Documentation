# BCP 47 is preferred, not selected

## Statement

BCP 47 is the current preference for expressing what a human language and
variant is. The initiative has not selected whether a tag is persisted
directly, mapped to an internal key or embedded in another identity model.

## Rationale

Descriptive tags address the cross-site ambiguity of local numbers without
requiring a server-installed locale to define identity.

## Consequences

This preference must not be documented as a Core decision. Script, region,
variant, private-use, API and legacy-migration rules still require wider
decisions.
