# Evaluate languageMode without assuming fallback parity

## Statement

Gerrit 97535 proposes `languageMode: overlays` or `free` for v15.
The participants preferred it to 97455's `fallbackType: connected` to
avoid confusion with backend Connected Mode. Overlay output must still
include independent records in the requested language (floating content).

## Rationale

PS1 converts legacy configuration and uses the presence of `0` to select
the overlay type. In the ordinary record-overlay path, a missing candidate
continues the chain; a present candidate denied by visibility stops it.
This is broader than 94510 and is not a proven equivalent for routing,
links, content selection or Extbase. Eric reported avoiding default
content with `0` omitted in his scenario; this is not universal proof.

## Consequences

Test `0` first, middle and last with visible and hidden base records and
translations on either side, distinguishing page resolution, base-record
selection and the overlay itself. The team did not conclude that entries
after `0` are unreachable or approve trimming saved chains. Preserve
single-language output and editorial compatibility through migration.
Neither Gerrit alternative is merged; there is no Core adoption decision.
