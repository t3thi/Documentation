# Technical connection does not require identical structures

## Statement

"Technically connected" means that Core retains an explicit cross-language
identity for one logical position. It does not require every language to render
the same records in the same order.

## Rationale

Maintained identity has value for comparison, ordering awareness,
synchronization and change tracking even when a language has a local structural
deviation.

## Consequences

Independent editorial outcomes must remain possible without using a missing
parent relation as their only storage contract.
