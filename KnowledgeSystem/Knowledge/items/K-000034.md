# A structure-layer and Editing-Language demonstrator now exists

## Statement

André demonstrated a prototype retaining `0` as hidden structural reference
while placing real content in language variants from `1` onwards. Its per-site
Editing Language controls Page Tree and Layout context. Missing translations
can display another language's label and flag; backend display fallback is
not itself an output-policy decision. A development control exposes the
structure for inspection. The demo resets its database, and its migration
command was untested by the presenter; production use was explicitly excluded.

## Rationale

This advances research from a product sketch to a demonstrator without proving
the full structural model. Pinned code confirms the prototype's stated scope
and shared visibility write path, not production readiness or runtime parity.

## Consequences

Comparison-selection persistence, always displaying the Editing Language,
missing-page and per-record translation actions, source choice, lifecycle and
migration remain validation work. Normal editors must not manipulate generated
structure; any later inspection feature needs server-side protection, not
only hidden controls. Direct structural blueprints and separate structural
permissions remain later ideas, not adopted release requirements. No v15 or
v16 delivery was promised. Core behavior and the maturity of `K-000011`'s
architectural hypothesis remain unchanged.
