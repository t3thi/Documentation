# New inline children should inherit the parent language by default

## Statement

When the editor creates a new inline or file-reference child without
explicitly selecting its language, the proposed bounded correction derives
that language from the referencing parent. An explicitly supplied child
language remains authoritative, so a deliberate parent-child language
difference is preserved. Existing child records are not relanguaged.

## Rationale

Current regressions can create new children in the Default Language when the
parent belongs to another language and the child language does not reach
DataHandler. Applying the parent language only as an implicit creation
default aligns hidden and visible language-field flows without prohibiting
valid mixed-language relations.

## Consequences

This statement records the earlier proposal, not current Core behavior.
Gerrit 95476 was abandoned on 2026-10-23, explicitly naming merged 87595
(TYPO3 v15) and 96783 (14.3) as its replacement. `K-000037` describes their
broader alignment contract, which can also overwrite a submitted child
language and realign existing siblings. The old proposal remains addressable;
its deliberate-difference guarantee must not be attributed to the successor.
