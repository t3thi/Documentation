# Language-comparison page icons open the record context menu

## Statement

The page icon in each Language Comparison column opens the corresponding
record context menu again, including actions for hiding or unhiding the
page translation. Gerrit 94673 and 14.3 backport 96935 merged on 2026-10-20.

## Rationale

`RecordIdentityRenderer::render()` has an opt-in `withContextMenu` argument,
defaulting to false. `LanguageColumn::getRecordIdentity()` enables it. The
bounded change does not add click-menu wrapping to every renderer consumer.

## Consequences

This closes the concrete comparison-icon work mentioned on 2026-10-02. It
does not implement prototype all-language visibility actions, Editing Language
or a new permission model. Static code and included tests were inspected;
no fresh interactive backend acceptance test was run in this audit.
