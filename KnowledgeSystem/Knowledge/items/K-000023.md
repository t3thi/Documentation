# Empty l10n_source translation lookup is implemented

## Statement

The translation lookup keeps `l10n_source` as the preferred relation and uses
`l10n_parent` when the source field is empty. This prevents
`DataHandler::localize()` from treating a valid existing translation as absent
and creating a duplicate.

## Rationale

The defect was documented in the reviewed July 31 meeting and Forge issue
110281. The main change and TYPO3 13.4 and 14.3 changes were subsequently merged.

## Consequences

The bounded fix preserves the distinction between translation source and
structural parent. It resolves the lookup defect but does not select a future
structural architecture.
