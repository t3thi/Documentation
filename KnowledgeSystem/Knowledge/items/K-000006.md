# Language All applies the complete record

## Statement

Current frontend selection includes records with `sys_language_uid = -1` for
every requested language, and overlay logic returns such a record unchanged.
The complete stored record therefore supplies current Language-All behavior.

## Rationale

This verified contract is broader than marking a small set of fields as
synchronized.

## Consequences

A compatible first replacement must reproduce complete-record behavior before
target-language selection or field-level exceptions are introduced.
