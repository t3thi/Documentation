# Current Core uses multiple coupled language contracts

## Statement

TYPO3 does not implement one translation model. Site-local language
configuration, `sys_language_uid`, `l10n_parent` or `l18n_parent`,
`l10n_source`, field synchronization, inferred backend modes and frontend
fallback each carry part of the behavior and influence one another.

## Rationale

The current Core contracts were checked against pinned code and explain why a
change to one value or relation can affect backend presentation, DataHandler
behavior and frontend output.

## Consequences

Migration and architecture work must characterize the interaction of these
contracts instead of treating any single field as the complete model.
