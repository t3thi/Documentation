# Strict output must remain distinct from fallback

## Statement

`fallbackType: strict` must render only records from the requested language.
`fallbackType: fallback` may render another language along an explicit chain.
A stored chain must not silently alter strict semantics.

## Rationale

The modes make different promises to editors. A merged fallback correction
exposed a regression in which hidden requested-language content could fall back
under `strict`.

## Consequences

The strict regression needs a bounded Core fix. A regional UK-to-English use
case should be expressed by fallback policy without forcing an unwanted
terminal default-language step.
