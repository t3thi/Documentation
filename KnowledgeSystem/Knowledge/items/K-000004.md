# Numeric language IDs are local configuration

## Statement

The same human language can receive different numeric IDs in separate sites,
while one numeric ID can be labelled as different languages across sites.
Neither the number nor a coincidentally matching locale is a reliable global
identity contract.

## Rationale

The behavior was observed in the Site Language configuration workflow and is
especially relevant to shared storage and cross-site record use.

## Consequences

Shared storage, metadata, import and export require an explicit semantic
identity mapping rather than assuming equal local numbers mean equal languages.
