# The interim Language-All marker is merged without replacing its semantics

## Statement

The merged mainline change introduces the internal
`LanguageMarker::ALL_LANGUAGES = -1` integer constant for current stored and
synthetic All-Languages contexts. Its documentation covers both uses. Clear
TCA and `SlugHelper` occurrences are included; LinkValidator retains its
fallback and query representation. Layout TypeScript retains the literal
with a PHP-marker synchronization comment. The merged TYPO3 14.3 backport
uses an untyped constant.

## Rationale

The official service confirms both merges, and inspection of the immutable
revisions confirms the bounded naming scope. The reviewed meeting treats it
as preparation, not replacement of Language-All handling.

## Consequences

The integer and language-field dependencies remain. The marker is explicitly
`@internal`, not a stable migration API for extension authors. A Default
Language marker and record/query abstractions are follow-up candidates, not
implemented by this change. The merge neither implements `K-000029`'s
replacement direction nor authorizes acceptance of `D-000002`. It does not
close the separate LinkValidator characterization question.
