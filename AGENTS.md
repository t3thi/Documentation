# Repository Agent Entry Point

The Git-native Knowledge System is isolated under `KnowledgeSystem/`.

For every task that reads, validates, generates or changes canonical knowledge,
Decision Records, Change Logs, Topic Syntheses, publication views, source
provenance or the generated Current State files, read and follow
[`KnowledgeSystem/AGENTS.md`](KnowledgeSystem/AGENTS.md) in full.

Historical transcript payloads under `Transcripts/` are restricted local
evidence. Do not stage, publish or expose them. The generated files
`MeetingMinutes/current-state.md` and `MeetingMinutes/current-state.de.md` must
not be edited directly.

For work unrelated to the Knowledge System, preserve the existing historical
documentation and meeting records.
