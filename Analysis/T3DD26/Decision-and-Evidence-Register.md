# T3DD26 Decision and Evidence Register

## Zweck, Geltungsbereich und Evidenzregeln

Dieses Register verdichtet die dauerhaft abgelegten Source Audits für die Session „Translation Handling in TYPO3: Where We Are and Where We Could Go“. Es ist weder eine Core-Roadmap noch eine technische Verifikation des aktuellen TYPO3-Codes. Aussagen über Core-Verhalten geben den in den Quellen dokumentierten Stand zum jeweiligen Datum wieder.

Ausgewertet wurden alle neun Dateien unter `Analysis/T3DD26/SourceAudits/` vollständig:

|---|---|
| `Analysis/T3DD26/SourceAudits/2023-weekly.md` | Weekly Minutes 2023 |
| `Analysis/T3DD26/SourceAudits/2024-H1-weekly.md` | Weekly Minutes Januar–Juni 2024 |
| `Analysis/T3DD26/SourceAudits/2024-H2-weekly.md` | Weekly Minutes Juli–Dezember 2024 |

| `Analysis/T3DD26/SourceAudits/2025-H2-weekly.md` | Weekly Minutes Juli–November 2025 |

| `Analysis/T3DD26/SourceAudits/2026-April-May.md` | Weekly Minutes und Transcripts April–Mai 2026 |
| `Analysis/T3DD26/SourceAudits/2026-June-July.md` | Weekly Minutes und Transcripts Juni–Juli 2026 |
| `Analysis/T3DD26/SourceAudits/Monthly-and-Meta.md` | Monthly Reports, `current-state.md`, `todos.md`, `overview.md` |

Für technische Semantik haben Weekly Minutes und Transcripts Vorrang vor Monthly-/Meta-Zusammenfassungen. Jüngere Evidenz qualifiziert ältere Aussagen. Eine Präferenz der Initiative ist keine angenommene Core-Entscheidung; eine Idee eines einzelnen Teilnehmers ist kein Teamkonsens. Jede Matrixzeile verwendet genau einen der zehn zulässigen Statuswerte. In der Spalte `Datum` steht bei positiven Befunden das maßgebliche Evidenzdatum; bei fortbestehenden offenen beziehungsweise negativen Befunden kann dort der Korpus-Stichtag stehen, während die Quellenzelle die jüngste konkrete Evidenz nennt.

## Status-Glossar

| Status | Verwendung in diesem Register |
|---|---|
| Current Core Behavior | In einer Quelle beschriebenes Verhalten des damaligen TYPO3-Stands; nicht automatisch live verifiziert. |
| Problem | Dokumentierte Inkonsistenz, Fehlfunktion, Kopplung oder redaktionelle Belastung. |
| Idea | Exploratives Modell oder Lösungsvorschlag ohne belastbare Richtungsentscheidung. |
| Discussed Direction | Wiederholt oder strukturiert diskutierte Richtung ohne klare Auswahl beziehungsweise Freigabe. |
| Preferred Direction | Explizite Präferenz oder strategisches Ziel der Initiative; weiterhin keine verbindliche Core-Roadmap. |
| Open Question | Semantik, Architektur, Migration, Zuständigkeit oder Machbarkeit ist offen. |
| Planned | Eine konkrete nächste Aktivität wurde vorgesehen, aber noch nicht begonnen oder abgeschlossen. |
| In Progress | Patch, Test, Analyse, Konzept oder Prototyp war nachweislich in Arbeit. |
| Implemented | Die Quelle belegt eine abgeschlossene beziehungsweise gemergte Änderung oder ein funktionierendes Artefakt. |
| Analytically Derived Recommendation | Aus Abhängigkeiten abgeleitete Empfehlung dieses Registers; ausdrücklich keine Initiative-Position. |
